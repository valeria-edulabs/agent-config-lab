# Release notes template

```
## <next version> - <today's date, YYYY-MM-DD>

### ✨ Features
- <one line per feat commit, rewritten for humans>

### 🐛 Fixes
- <one line per fix commit>

### 🧹 Other
- <docs, refactor, chore...>
```

Rules:
- Next version: bump the minor number of the last tag (v0.1.0 → v0.2.0).
- Write for users, not developers: describe the effect, not the code.
- Skip empty sections.
