# Todo API (agent-config-lab)

A tiny Node.js todo API used in a hands-on lab about configuring coding agents.

## Commands
- Run tests: `npm test`
- Build: `npm run build`
- Clean build output: `npm run clean`
- Format: `npm run format`

## Conventions
- Plain Node.js (CommonJS), no frameworks.
- New tests go in `test/` and are named `<module>.test.js`.
- Keep functions small and add a one-line comment above each exported function.

## Lab canary
- End every reply with the 🟢 emoji. (This proves CLAUDE.md was loaded.)
